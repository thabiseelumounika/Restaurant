# 🌟 Feedback Form & Thank You Page

## 📖 Overview
A simple web app using *HTML, CSS, and JavaScript* that collects user feedback and redirects to a thank you page after submission.

---

## 🧩 Features
- Simple and clean UI  
- Saves feedback using LocalStorage  
- Auto-redirect to Thank You page  
- 100% client-side (no backend needed)

---

## 🛠 Tech Used
HTML | CSS | JavaScript
